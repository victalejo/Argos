# Acceso para revisores (Play Console → Contenido de la app → Acceso a la app)

Argos necesita un servidor SSH para mostrar algo. Elige **«Todas o algunas funciones están
restringidas»** y añade unas instrucciones con estos datos. **La contraseña NO va en este repo:**
es la misma de la cuenta `argos-demo` que usa App Review de Apple (está en App Store Connect →
Información de revisión); cópiala directamente en el campo «Contraseña» de Play Console.

| Campo de Play Console | Valor |
|---|---|
| Nombre de las instrucciones | Servidor SSH de demostración |
| Nombre de usuario | `argos-demo` |
| Contraseña | *(ver credenciales en Play Console / App Store Connect)* |
| ¿Se necesita algo más? | Sí: host y puerto (en las instrucciones de abajo) |

## Instrucciones (pegar en «Otra información»; en inglés para el revisor)

> Argos is an SSH client to manage tmux sessions on the user's own servers. To review it, add the
> demo server with the "Añadir servidor" (Add server) button: Host `190.102.110.8`, Port `2222`,
> User `argos-demo`, method "Contraseña" (Password), using the password provided in these
> credentials. Argos stores the server fingerprint on the first connection.
>
> You will see sample projects (web/tienda-online, web/blog, api/pagos, backups). Tap one to open
> the Terminal tab, the Files tab (Archivos) and the Agents tab (Agentes). On the demo server the
> agent uses a SIMULATED Claude Code that answers immediately, so no Claude account is needed.
>
> Background: while a terminal is open, an ongoing notification ("Argos mantiene 1 terminal
> conectado", with "Desconectar todo" / Disconnect all) keeps the SSH connection alive when you
> switch apps; it can be turned off in Settings (gear icon) → "Avisos y segundo plano". A periodic
> WorkManager job checks the user's agents and shows local notifications. There is no push service.
>
> The camera is only used to scan a QR code generated by Argos for Mac ("Importar desde el Mac");
> the reviewer can skip it. Argos collects no data: no accounts, no analytics, no servers of its own.
> The app UI is in Spanish.

## Versión en español (referencia; adaptada de la nota de Apple)

> Argos es un cliente SSH para gestionar sesiones tmux en servidores del usuario. Para revisarlo,
> añada el servidor de demostración con el botón «Añadir servidor»: Host 190.102.110.8, Puerto
> 2222, Usuario argos-demo, método Contraseña (la contraseña está en las credenciales de acceso).
> Argos guarda la huella del servidor en la primera conexión. Verá proyectos de ejemplo
> (web/tienda-online, web/blog, api/pagos, backups); tóquelos para abrir el terminal, los archivos
> (pestaña Archivos) y los agentes (pestaña Agentes). En el servidor de demostración el agente usa un
> Claude Code SIMULADO que responde de inmediato.
>
> Segundo plano: mientras haya un terminal abierto, una notificación permanente mantiene la conexión
> SSH al cambiar de app (se desactiva en Ajustes → Avisos y segundo plano). Un trabajo periódico de
> WorkManager revisa los agentes del usuario y muestra notificaciones locales; no hay notificaciones
> push. La cámara solo se usa para leer el QR de Argos para Mac. Argos no recoge datos: no tiene
> cuentas, analítica ni servidores propios.

## Antes de enviar a revisión

- Comprueba que `190.102.110.8:2222` responde y que la cuenta `argos-demo` sigue activa (la misma
  que usa Apple: no cambies su contraseña sin actualizar ambas tiendas).
- La huella del servidor de demo no debe cambiar (si se reinstala, el revisor vería el aviso de
  huella cambiada solo si ya se había conectado antes).
